Welcome to my blog! This site is powered by [Hugo](https://gohugo.io/) and the [Stack theme](https://github.com/CaiJimmy/hugo-theme-stack).

## What you will find here

- **Posts**: tech notes and learning journals
- **Archives**: browse everything by time
- **Categories / Tags**: find content by topic

## How it works

1. Create a new post with `hugo new content post/xxx/index.md`
2. Preview locally with `hugo server -D`
3. Push to GitHub — Actions will build and deploy to `https://yinwwwwww.github.io/` automatically

Thanks for visiting!
