欢迎来到我的博客！这是基于 [Hugo](https://gohugo.io/) 和 [Stack 主题](https://github.com/CaiJimmy/hugo-theme-stack) 搭建的个人站点。

## 这里有什么

- **文章**：技术与学习笔记
- **归档**：按时间浏览所有内容
- **分类 / 标签**：按主题快速检索

## 写作与部署

1. 使用 `hugo new content post/xxx/index.zh.md` 新建文章
2. 本地预览：`hugo server -D`
3. 推送到 GitHub 后，Actions 会自动构建并部署到 `https://yinwwwwww.github.io/`
